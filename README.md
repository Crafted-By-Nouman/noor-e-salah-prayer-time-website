# 🕌 Noor-e-Salah — Islamic Prayer Time Website

**Live Demo ➤** [Click Here](https://crafted-by-nouman.github.io/noor-e-salah-prayer-time-website)

> 🌙 _"Illuminate Your Day with the Light of Every Prayer"_

Noor-e-Salah is a super creative, fully responsive, modern Islamic Prayer Time website designed using **pure HTML, CSS, and JavaScript**.  
It offers accurate prayer timings, beautiful UI, and spiritually immersive features — all wrapped in an elegant Islamic design.

---

## ✨ Features

- 📍 Auto-detect user location for local prayer times
- 🕌 Fetch accurate prayer times via **Aladhan API**
- 🕰️ Live digital clock with seconds
- 📅 Gregorian & Hijri date side-by-side
- ⏳ Countdown to next prayer with highlight
- 🔔 Azan alert (with audio control)
- 🧭 Qibla Direction compass (optional)
- 📖 Daily **Quran Ayah** & **Hadith of the Day**
- 🌗 Dark Mode / Light Mode toggle
- 🌄 Dynamic backgrounds based on prayer or time
- 🧕 Beautiful animated Islamic design (glassmorphism, stars, mosque theme)
- 📱 100% Responsive on all devices
- 🧩 Multi-language ready (English / Urdu / Arabic – coming soon)
- 💫 Future updates planned: Tasbeeh Counter, Islamic Calendar, Jummah/Eid Countdown

---

## 🛠️ Built With

- **HTML5** – Semantic structure
- **CSS3** – Styling, animations, dark mode, glassmorphism
- **JavaScript** – API handling, live updates, location, logic
